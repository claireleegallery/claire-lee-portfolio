# Claire Lee — portfolio gallery

A responsive, gallery-inspired personal portfolio built with HTML, CSS, and a small amount of JavaScript. The project uses horizontal scroll snapping and accessible previous/next controls to browse the featured work. No build step or framework is required.

## Files

- `index.html` — portfolio, styles, and gallery interactions
- `assets/marathon-homepage.png` — Marathon screenshot used in the first gallery frame

## Publish with GitHub and Vercel

1. Create a GitHub repository named `claire-lee-site` in your personal account or organization. Leave it empty when creating it.
2. Upload `index.html`, `README.md`, and the `assets` folder (including `marathon-homepage.png`) to the repository and commit them to `main`.
3. In Vercel, choose **Add New → Project**, connect GitHub if prompted, and import the repository. If it belongs to an organization, grant Vercel's GitHub app access to that repository.
4. Configure the project as **Other** with no build command and `.` as the output directory, then deploy.

Vercel will provide a `*.vercel.app` URL. New commits to the connected GitHub repository will trigger deployments automatically.

## Before publishing

- Review the work summaries and employment details.
- Confirm the email address and Marathon link are the ones you want public.
- Add a LinkedIn profile link or resume download if you want visitors to have those options.
